### Cost Estimator Module
**Live Project Cost Calculator:**

**Input Parameters:**
1. **Roof Area (m²)** - Dynamic input field
2. **Material Type** - Dropdown selector:
   - Cambridge Shingles (KES 850/m²)
   - Stone-Coated Tiles (KES 1,200/m²)
   - Corrugated Sheets (KES 450/m²)
3. **Roof Pitch** - Selector with multipliers:
   - Low Pitch (≤20°): 1.0x multiplier
   - Medium Pitch (20°-45°): 1.15x multiplier
   - High Pitch (>45°): 1.35x multiplier
4. **Labour Percentage** - Slider (0-100%):
   - Default: 25% of material cost

**Real-Time Calculations:**
- Material Cost = Area × Material Price × Pitch Multiplier
- Labour Cost = Material Cost × (Labour % / 100)
- Total Estimated Cost = Material Cost + Labour Cost
- All displayed in KES (Kenyan Shillings)

**Summary Card:**
- Material cost breakdown
- Labour cost breakdown
- Total project cost in KES
- Live updates as inputs change

### State Management:
- UserContext for role-based dashboard switching
- Local component state for form inputs
- No external state library required for demo

## Getting Started

To run the dashboard locally:
```bash
pnpm install
pnpm dev
```

Visit `http://localhost:3000` to see the dashboard.

**To switch user roles:**
1. Click on the user profile section in the sidebar
2. Select a different role from the dropdown
3. Dashboard adapts to show role-specific data
